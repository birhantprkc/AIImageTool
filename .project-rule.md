# ZeroVision Project Directives
- **ZeroUI (ZU) Integration:** All design tokens, editors (`ToggleSwitch`, `RatingControl`, `ProgressBarControl`), and GPU render optimizations (`RenderOptimizer`) MUST consume `ZeroUI.Core` and `ZeroUI.Wpf` strictly via local NuGet packages (`<PackageReference>`). Never use `<ProjectReference>` to ZeroUI.
- **Develop Pipeline:** Maintain non-destructive 32-bit float Linear Light color space for all image filters and processing operations.
- **Zero-GC Hot-Path:** Use `ZeroBufferPool.RentByteArray` and `Span<T>` in tight render and conversion loops to prevent Large Object Heap (LOH) GC Gen2 spikes (`R_PERF`).
- **Universe Architecture:** Decouple AI vision modules (Upscaler, FaceRestorer, VisionTagger) into autonomous plugins communicating via IPC and EventBus (`ZeroVision.Shared`). Deleting a plugin module must never break host compilation (`R_UNIVERSE`).
- **Hardware Acceleration:** Leverage DirectML / ONNX Runtime in background host process (`ZeroVision.Host`) to prevent UI thread blocking.
- **UI & Theming:** Strictly adhere to C# WPF Desktop UI & Theming Standards (`[AgentOption]/standards/csharp/wpf-ui.md`).
- **Zero Memory Leaks:** Ensure proper native bitmap buffer recycling and GPU memory management across editing operations.
